# AliCCP latent cross-task prediction diagnostic — preregistration

Status: frozen before implementation or formal runs. This is an information diagnostic, not a novelty or deployment claim. Branch `exp/aliccp-latent-cross-task-diagnostic` starts at pure fair baseline `8133d32`; no RP or ensemble code is inherited.

## Question and pre-run audit

Does the frozen Stage-1 CTR/CVR prediction pair add BSI ranking information beyond a separately trained BSI head's own prediction? Stage-1 `MPTRec.predict` emits CTR/CVR fused predictions, all functions of input features without BSI labels. The new-task head predicts BSI from frozen Stage-1 representations. The earlier fair protocol fixes `p2M-v500k-t1M` (train/dev/test), 2M/500k/1M rows, seed `1688723512`, and content-addressed Stage-1 `s1-5c060b9c-m1688723512-e3-3a30e2c0` (fingerprint `5c060b9c5c9d0e235ec815e1b488b9dec222fc37887ad2eedd2afadc82bdd0d8`). Local Stage-1 metadata and data files were checked before this document; the 2M train prefix has 16,921 BSI negatives, official dev 3,795, test 10,024. CVR positives are scarce, so CVR-specific attribution is descriptive only. Stage-1 saw CTR/CVR labels on all 2M training rows but never BSI labels; this transductive exposure is disclosed, not hidden.

GO for one diagnostic screening seed because both BSI classes are supported and the Stage-1 checkpoint exists. Before fitting, abort as NO-GO if checkpoint/fingerprint mismatches, any split has fewer than 100 BSI negatives, frozen prediction variance of both old tasks is below `1e-8`, or backbone freeze invariants fail. No official test inspection until all three diagnostic probes are frozen.

## Frozen protocol

Use the original data prefixes, no rebalancing, no dataset mutation. Split train rows in file order: A `[0,1_400_000)` to train one baseline `NewTask` BSI head; B `[1_400_000,1_700_000)` to fit diagnostic probes; C `[1_700_000,2_000_000)` for out-of-sample mechanism check. Save index-range hashes, counts, labels, and source fingerprint. BSI head uses same hyperparameters as fair Stage-2 short run: 5 epochs maximum, patience 2, batch 2000, Adam `1e-4`, checkpoint by official dev BSI AUC. All probes share that one frozen BSI head and Stage-1 checkpoint. The BSI head never trains on B/C. Stage-1 may have seen CTR/CVR labels on B/C, but no BSI label; official dev/test labels cannot fit probes or select their regularization.

For each row collect raw BSI probability and frozen CTR/CVR fused probabilities. Clip each to `[1e-6,1-1e-6]` and logit-transform. Fit three `sklearn.linear_model.LogisticRegression` probes on B BSI labels, `C=1.0`, L2, `max_iter=200`, deterministic solver `lbfgs`, with standardization means/scales computed only on B: (1) `base`: BSI logit only; (2) `full`: BSI, CTR, CVR logits; (3) `shuffle`: BSI plus jointly permuted CTR/CVR logits, with fixed NumPy seed `20261008`, separately permuted in each split before scoring, to preserve old-task marginal distributions and parameter count but destroy row-level alignment. Fit shuffle on B's permuted columns. No hyperparameter grid, no threshold tuning. C and official dev/test are evaluated once per frozen probe; permutation RNG state and index hashes are artifacts. B label counts, feature variance, Pearson correlations, logistic coefficients, convergence, and each arm's AUC are recorded. AUC is computed from per-row raw labels/predictions and independently rederived.

Main incremental statistic: `Δtest = AUC(full) − max(AUC(base), AUC(shuffle))`; supporting `ΔC` and `Δdev` use the same formula. Positive information signal requires `Δtest >= +0.001`, `ΔC >= +0.001`, `Δdev >= 0`, nonconstant old-task predictions on B/C/test, and all identity/freeze/data gates. If not, mark NO-GO for extension, retain negative result. This is a one-seed screening result only; if positive, an independent seeds2–3 branch from this prereg commit may repeat the fixed protocol. No method tuning or new task architecture on this branch.

Classification of paired `Δtest`: `>= +0.001` positive; `(-0.02,+0.001)` no clear improvement; `<= -0.02` clear decline. This new classification does not overwrite any historical preregistration. The result interpretation must distinguish apparent BSI head calibration improvement from truly incremental old-task information; `full > base` alone is insufficient if `shuffle` matches it. No claim that these probes improve MPT-Rec itself.
