# AliCCP 参数高效集成：五种子配对结果

## 协议与来源

本分支按 `specs/2026-10-08-aliccp-ensemble-seeds2-5-design.md` 的冻结清单补 canonical seed 1688723740、1688738016、1688749593、1688762746。seed1=1688723512 的三臂原始结果来自独立分支 `exp/aliccp-parameter-efficient-ensemble` 的 `c12d0b7`，详见该分支结果记录；本分支代码 `5c38bfc` 是同一实现的 cherry-pick。五种子各自使用同 seed、同 AliCCP `p2M-v500k-t1M` 前缀、同冻结 Stage-1、同 2M/500k/1M 样本、batch 2000、Adam 1e-4、最多 5 epoch/patience 2。B 为原始 NewTask，C 为同主头+单 rank-16 残差，E 为同主头+双 rank-8 残差的预测平均。C/E 均 9169 可训练参数，B 为 8129；不宣称等算力。

每个新增正式 run 的身份 `git.dirty=false`，A1/A2/A4/A5/A6 PASS、A3 SKIP；B1/B4 继承性 FAIL 在 SUMMARY 原样保留。三臂配对解析器对每个 seed 的身份、标签、预算、Stage-1 meta/backbone SHA、原始预测、val 选点和 checkpoint SHA 均给出 `all_ok=true`；本线程另外用 sklearn 直接读取 raw `predictions.pt` 重算 test/val AUC、成员 AUC 和标签相等性，不采用 CC 口头结论。新四种子的 12 个 run ID、逐臂 val/test AUC、全部 A/B 门禁和 Stage-1 ID 见 `artifacts/aliccp_bench/SUMMARY.md`；原始配置、指标、门禁、预测和权重保留于对应 `artifacts/aliccp_bench/runs/<run_id>/`，日志在 `artifacts/aliccp_bench/logs/`。seed1 原始 run ID 见原方向分支结果记录。

## 预注册裁决

「组合方案值得后续研究」要求五种子 E−B、E−C 均值各 ≥+0.001、至少 3/5 种子两项都 ≥+0.001、平均 Δval 同向、至少 3/5 机制未塌缩。尽管两个 test 均值为正，**同时达标仅 1/5，机制未塌缩仅 2/5**，故整体 **NO-GO：效用与双头机制均不稳定**。平均推理也未带来可观察的增益。关闭本参数高效集成变体，不在本分支调 rank、挑 seed 或延长预算。C 单头在个别种子有效属于探索线索，不改变本次预注册失败结论；若未来研究须另提可证伪假设并独立预注册。

原始有效负结果保留；没有将失败改写为「提升」。本结果只涉及实验数据判断，不涉及论文表述或图表。
