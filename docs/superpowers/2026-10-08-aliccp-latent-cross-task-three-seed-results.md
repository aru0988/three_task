All three runs use the same prefix fingerprint `5c060b9c5c9d0e235ec815e1b488b9dec222fc37887ad2eedd2afadc82bdd0d8`, budgets train/dev/test 2M/500k/1M, A/B/C train partition 1.4M/300k/300k, 5-epoch/patience-2 BSI head, B-only logistic probe fitting, and one official test evaluation after all probes freeze. `base` uses only the BSI-head logit; `full` additionally uses **aligned** frozen CTR/CVR logits; parameter-matched `shuffle` instead jointly permutes those old-task logits by row. Every test Δ exceeds the added +.001 positive classification threshold, but seed2 fails the separately frozen internal C requirement. Mean paired test Δ = **+.041749234**, sample SD = **.016525035**, t-based two-sided 95% CI **[+.000698771,+.082799697]** (n=3), worst seed **+.024262991**. Complete-signal count **2/3**, so the preregistered group rule (at least 2/3 complete and mean Δtest≥+.001) passes for a **follow-up information hypothesis**. The lower CI bound is below +.001; do not claim stable magnitude. Full absolute test AUC ranges .445745–.519184, and baseline probes are below .5 in every seed, so this does not establish a useful deployed predictor.
